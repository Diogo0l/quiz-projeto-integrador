# Quiz: Cybersegurança — Segurança de Computadores Pessoais

Site de quiz sobre "Cybersegurança - Segurança de Computadores Pessoais", desenvolvido como parte do Projeto Integrador do curso Assistente de TI no SENAC.

## Descrição
Este repositório contém um site simples de quiz (HTML/CSS/JavaScript) que testa conhecimentos básicos sobre segurança de computadores pessoais. Ideal para estudo, revisão e demonstração do projeto integrador.

## Funcionalidades
- Conjunto de perguntas com múltipla escolha
- Contagem de pontuação
- Feedback ao final do quiz
- Botão para reiniciar o quiz
- Layout responsivo (suporte básico para dispositivos móveis)

## Tecnologias
- HTML
- CSS
- JavaScript

## Executando localmente
1. Clone o repositório:
   git clone https://github.com/Diogo0l/quiz-projeto-integrador.git
2. Entre na pasta do projeto:
   cd quiz-projeto-integrador
3. Abra o arquivo `index.html` no seu navegador ou rode um servidor local (recomendado):
   - Com Python 3:
     python3 -m http.server 8000
     Depois acesse http://localhost:8000
4. Site: https://quiz-projeto-integrador.vercel.app

## Como usar
- Abra o site no navegador.
- Selecione uma resposta para cada pergunta.
- Ao final, veja sua pontuação e o feedback.
- Use o botão "Reiniciar" para fazer o quiz novamente.
